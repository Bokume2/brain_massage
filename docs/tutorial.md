# BrainMassage言語仕様(簡易版)
Brainf*ck未経験者への解説を想定した、最低限の仕様のみを扱う仕様書兼入門チュートリアルです。  
意図的に一部の仕様を隠蔽した表現を用いるため、正確な仕様は完全版の言語仕様(現在整備中)を参照してください。  

## 変数
BrainMassageにおける変数は、他のプログラミング言語の一般的な概念と同じく、プログラム中で変化するデータを保存しておくための記憶域です。  
変数の総数はコンパイル時やプログラム実行前に予め決まっており、デフォルトでは4096個です。  

### データ型
変数のデータ型はすべて8ビット長符号なし整数です。つまり、1つの変数には`0`～`255`の整数値を保存できます。  
BrainMassageは変数のオーバーフローに対してエラーや警告を出さず、正常な動作としてラップアラウンドを行います。値が`255`の変数に`1`を加えると`0`になり、値が`0`の変数から`1`を引くと`255`になります。  
また、一度も代入を行っていない変数の初期値は`0`です。  

### 変数名
変数名は各変数に固定で割り当てられており、`v0`、`v1`のように`v〈インデックス〉`の形式です。  
インデックスには`0`～`(〈変数の総数〉 - 1)`の整数を指定することができます。  

## リテラル
BrainMassageではデータとして整数のみを扱うため、リテラルも整数のみを扱います。  
整数リテラルは、`0`、`10`のように10進数の数値をそのまま表記する10進表記と、`0x0`、`0xA`のように先頭に`0x`を付けて16進数で表記する16進表記のいずれかで記述することができます。16進表記に用いる各種アルファベットは大文字と小文字を区別しません。変数のインデックスにも10進表記と16進表記の両方を利用可能ですが、変数名の`v`の部分は必ず小文字にしてください。    

## 代入文
変数の値は、代入文によって変更することができます。  
代入文には、単純代入、加算代入、減算代入の3種類があります。いずれの代入文も末尾に`;`を付けますが、文の直後に改行、`}`またはファイル末尾がある場合、`;`を省略することができます。ここでいう「直後」は、0個以上の半角空白または水平タブを挟んだあとでも構いません。  

### 単純代入
変数にリテラル値やユーザーの入力した値をそのまま設定します。  
`〈変数名〉 = 〈右辺値〉;`の形で記述します。右辺値は整数リテラルか、後述する入力関数の呼び出しのいずれかです。  
例えば、`v0`に値`84`を設定する場合は`v0 = 84;`や`v0 = 0x54;`のように記述します。  

### 加算代入
変数の値を増加させます。  
`〈変数名〉 += 〈整数リテラル〉;`の形で記述します。加算代入および減算代入の右辺には入力関数の呼び出しは使えません。  
例えば、何らかの値が入った変数`v1`の値を`67`増加させたい場合は`v1 += 67;`のように記述します。  

### 減算代入
変数の値を減少させます。  
`〈変数名〉 -= 〈整数リテラル〉;`の形で記述します。  
例えば、何らかの値が入った変数`v2`の値を`32`減少させたい場合は`v2 -= 0x20;`のように記述します。  

## 組み込み関数
BrainMassageは、プログラムのユーザーに対する入出力のために、入力関数`get`と出力関数`put`の2つの組み込み関数を提供します。  
逆に、組み込み関数以外の関数を新しく定義する機能はありません。  

### 入力関数`get`
標準入力から文字コードの先頭1バイトを読み取り、1つの変数をその値で上書きします。  
呼び出しは`get()`で記述し、単純代入の右辺値として呼び出すことができます。  
読み取った入力は標準入力から消費されるため、2バイト以上の入力であってもそのバイト数だけ入力関数を呼び出すことですべて読み取ることができます。  
文字コードセットに関してはこの仕様では定義しません。  
例えば、ユーザー入力を変数`v3`に読み込みたい場合は`v3 = get();`のように記述します。  

### 出力関数`put`
1つの変数の値を文字コードとして解釈し、標準出力に書き出します。  
呼び出しは`put(〈変数名〉)`の形で記述し、`;`を付けて出力関数の呼び出し文として呼び出すことができます。この`;`も代入文と同じ条件の下で省略可能です。  
例えば、変数`v4`の値を文字コードと解釈して出力したい場合は`put(v4);`のように記述します。  

## while
whileは条件付きループです。条件に指定した変数の値が`0`でない間、ループ内のコードを記述の順序通りに繰り返し実行します。  
`while (〈変数名〉) { 〈文またはwhile〉... }`の形で記述します。文とは代入文または出力関数の呼び出し文のいずれかで、`{}`内の文またはwhileは0個以上の任意の個数記述できます。  
構文定義から分かる通り、whileは入れ子にすることが可能です。  
例えば、`while (v5) { v5 -= 1; v6 -= 1 }`と記述すると、`v5`の値が`0`になるまで`v5`と`v6`の値を`1`ずつ減らします。(これは`v6`から`v5`の値を引く簡単なイディオムです)  

## プログラム全体の構成
BrainMassageの1つのソースコードは、文またはwhileを0個以上の任意の数並べて記述したものです。文やwhileは、記述された順序の通りに順次実行されます。  
BrainMassageでは、1つのプログラムは必ず全体を1つのソースファイル内に記述しなければなりません。また当然、1つのソースファイル内に2つ以上のプログラムを記述してはいけません。  

## ソースコードの細かい体裁
変数名、リテラル、関数名、演算子などの間には、半角空白、水平タブ、改行のいずれかの空白類文字を任意の数記述しても構いません。ただし、前述した`;`の省略の条件は遵守してください。  
この空白類文字の扱いは、例えばC言語によく似たものなので、必要に応じてC言語などの他言語の仕様を参考にしてください。ただし、厳密に同じ扱いであることを保証するものではありません。
